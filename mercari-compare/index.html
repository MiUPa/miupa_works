Chrome Extension

Amazonで買う前に、
メルカリの中古価格をその場でチェック

「それ、メルカリなら安いよ」は、Amazon.co.jpの商品ページを開くだけで、メルカリで今買える中古の候補と、Amazon価格との差額をその場に表示するChrome拡張機能です。別タブを開いて商品名をコピペ検索し直す手間をなくします。無料で使えます。

Chromeに追加（Chrome Web Store） 使い方を見る

無料 ・ アカウント登録不要 ・ Chrome Web Store で公開中

実際の画面：Amazonの商品ページでの表示例（Chrome Web Store掲載中のスクリーンショット）

What it does

何ができるか

新品を買った直後に、メルカリでずっと安い出品を見つけて悔しい思いをしたことはないでしょうか。この拡張機能は、Amazonの商品ページ上でその確認を済ませるためのものです。

その場で候補と価格差を表示

販売中の候補だけを、価格とAmazon価格との差額つきで表示します。候補をクリックすればメルカリの商品ページへ移動できます。

検索は自動

商品名・ブランド・型番・JAN / ISBN・色・サイズから、メルカリ用の検索語を自動で組み立てます。検索語の手動調整、並び替え、表示件数の切り替えもできます。

「本体ではない出品」を除く

ケース・カバー・フィルム・空箱・ジャンク・付属品のみといった出品を自動で除外します。比べたいのは本体の価格なので、その手前のノイズを取り除きます。

対象ジャンルは広め

本・ゲーム・家電・日用品・コスメなど、「中古で十分だから安く買いたい」買い物の前にどうぞ。

How to use

使い方（3ステップ）

STEP 1

Chromeに追加する

Chrome Web Storeのページから「Chromeに追加」を押します。料金は無料で、登録も不要です。

STEP 2

Amazonの商品ページを開く

いつもどおりAmazon.co.jpで商品ページを開くだけです。拡張機能が自動でメルカリの中古候補を探します。

STEP 3

候補と価格差を確認する

ページ上に表示された候補と価格差を見て、新品で買うか中古にするかを判断します。気になる候補はクリックでメルカリへ。

FAQ

よくある質問

データの扱いについて：独自サーバーは使っておらず、設定と短時間の検索キャッシュはお使いのブラウザの中にだけ保存されます。

料金はかかりますか？

無料です。Chrome Web Storeから追加するだけで使えます。

対応しているサイトはどこですか？

Amazon.co.jpの商品ページに対応しています。ページを開くと、その商品の中古候補をメルカリから探して表示します。比較先はメルカリです。対応ブラウザはGoogle Chrome（PC版）です。

使うのにアカウント登録は必要ですか？

拡張機能自体への登録は不要です。候補の購入手続きはメルカリ側で行います。

データが外部に送信されることはありますか？

独自サーバーは使っていません。設定と短時間の検索キャッシュは、お使いのブラウザ内（chrome.storage.local）にだけ保存されます。収集するデータは比較に必要なページ内容のみで、第三者への販売や、目的外の利用はしません。

表示される価格は正確ですか？

表示価格は取得時点のメルカリの出品情報です。売り切れや価格変更のほか、中古品の状態は出品ごとに異なるため、購入前に必ずメルカリの出品ページでご確認ください。

Amazonやメルカリの公式ツールですか？

いいえ。Amazon / Mercari 公式のものではなく、個人が開発している非公式ツールです。メルカリ側の仕様変更により、一時的に動作しなくなる場合があります。

Amazonの商品ページを開く、いつもの流れのまま使えます。
