GASフォーム自動化キット （コードを無料公開中）

Google フォームに申し込みがあるたびに発生する「スプレッドシートへの転記・受付メールの送信・担当者への連絡」を、Google Apps Script（GAS）で自動化する一式です。セミナー申込、予約受付、問い合わせ、資料請求など、フォームの後処理が定型の業務で使えます。コードは GitHub で無料公開しています。

できること

1. 整形して記録

回答を「受付ログ」シートに整形して蓄積します。返信・通知の成否も行ごとに記録されるので、「送れたかどうか」を後から追えます。

2. 自動返信メール

申込者へ受付完了メールを即時送信。本文はテンプレート式で、申込者の名前や申込内容を自動で差し込めます。

3. Slack / LINE 通知

新しい申込の内容を、Slack・LINE（公式アカウントの Messaging API）・管理者メールに即時通知。Webhook URL やトークンはコードに書かず、スクリプト プロパティで管理します。

導入の流れ

  1. Google フォームと、回答スプレッドシートを用意する
  2. スプレッドシートの Apps Script エディタに、本キットの5ファイル（.gs）を貼り付ける
  3. Config.gs で返信メールの文面などを自社用に編集する
  4. （任意）Slack / LINE の通知先をスクリプト プロパティに登録する
  5. セットアップ関数を1回実行すれば、あとはフォーム送信のたびに自動で動く

コードの一部

処理の中心は、フォーム送信トリガーから呼ばれるこの関数です（抜粋）。

function handleFormSubmit(e) {
  const record = eventToRecord_(e);   // 回答を {見出し: 回答} の形に変換
  processRecord_(record);             // ログ記録 → 自動返信 → Slack/LINE通知
}

function processRecord_(record) {
  const email = findEmail_(record);   // メールアドレスの列を自動検出
  if (email) sendReplyMail_(record, email);
  const text = buildNotificationText_(record);
  if (getSecret_('SLACK_WEBHOOK_URL')) notifySlack_(text);
  if (getSecret_('LINE_CHANNEL_ACCESS_TOKEN')) notifyLine_(text);
  appendLog_(record, status);         // 受付ログへ整形して記録
}

カスタマイズ例（案件ごとに調整）

  • 条件分岐： 申込内容（希望コース・日時など）に応じて返信文や通知先を切り替える
  • カレンダー連携： 予約フォームの内容から Google カレンダーへ仮予定を自動登録
  • PDF自動生成： 回答内容から受付票・請求書PDFを生成し、自動返信に添付
  • 締切連動： 定員・締切に達したらフォームの受付を自動停止
  • 顧客管理連携： 既存の顧客シートへの転記、重複申込の検知
